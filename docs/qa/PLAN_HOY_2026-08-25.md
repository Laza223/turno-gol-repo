## 1. La división de tareas entre los dos complejos

Esto es lo que hace que el día entre. Cada complejo tiene un papel y no se
mezclan:

| | `complejo-titi` | `complejo-elite-futbol` |
|---|---|---|
| Cuenta de MP | de Tiziana | **tuya** (la misma del master) |
| Papel | **la plata real** | **el laboratorio de relojes** |
| Paga la suscripción SaaS | ✅ sí, $100/mes → tu cuenta | ❌ imposible (auto-pago) |
| Cobra señas | ✅ sí, ← vos como jugador | — |
| Se le adelantan fechas | ❌ **no** | ✅ sí |

**Por qué las simulaciones van en Elite y no en titi**: el cron
`reconcile-subscriptions` corre cada hora y, para todo tenant con
`mp_subscription_id` no nulo, le pregunta a MercadoPago cuál es el estado real
del preapproval. Si le adelanto fechas a un tenant con suscripción viva, el
reconciliador pisa la simulación o dispara una alerta de desync. Elite no tiene
ni va a tener preapproval vivo, así que ahí las fechas se pueden mover libres.
